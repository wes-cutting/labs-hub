## 6. Commands & gotchas (cold-start)

```sh
# Reach the Pi (passwordless SSH already set up from this Mac):
ssh wesker@192.168.1.185

# Throwaway SPIKE-01 stack (still running):
cd ~/spike01 && sudo docker compose ps
sudo docker compose down         # tear down when done
rm -rf ~/spike01                 # reclaim disk (incl. the 872 MB synthetic fixture)
```
- **Pi is on Wi-Fi** (`wlan0`); wire Ethernet for cleaner multi-client throughput later.
- **mDNS `raspberrypi.local` did not resolve** — use the IP `192.168.1.185`.
- **macOS "Local Network" permission** must be ON for a browser to reach the Pi's LAN IP.
- **Pi 5 has no HW H.264 encoder** — Jellyfin transcode = software libx264; keep it single-stream.
