## 6. Commands & gotchas (cold-start)

```sh
ssh wesker@192.168.1.185                 # passwordless SSH from this Mac; Pi on Wi-Fi
cd ~/spike01 && sudo docker compose ps   # the services (Jellyfin/Homebox)
sudo docker ps                           # + homepage (:3000), portainer (:9000)
```
- **Memory cgroup is enabled** now (`cgroup_enable=memory cgroup_memory=1` in `/boot/firmware/cmdline.txt`) — required for per-service RAM metrics/limits.
- **Homebox needs `HBOX_AUTH_API_KEY_PEPPER`** (≥32 bytes) or it panics.
- Pi 5 has **no HW H.264 encode** → keep Jellyfin transcoding single-stream.
- The seed containers were started ad-hoc/`docker run`; **LH-S1's job is to make them a clean, reproducible Compose definition** (some lack a restart policy).
