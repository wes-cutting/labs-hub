## 6. Commands & gotchas (cold-start)

```sh
ssh wesker@raspberrypi.local && cd ~/labs-hub   # mDNS name; survives IP/network changes
make gate                         # yamllint + compose config (3 files) + shellcheck
make up                           # hub + Jellyfin + budgeteer demo
make smoke HOST=localhost         # Homepage + Portainer + Jellyfin + budgeteer /api/health
```
- Services: Homepage `:3000`, Portainer `:9000`, Jellyfin `:8096`, **Budgeteer demo `:3010`**, Homebox `:7745` (ad-hoc).
- Data-root `/srv/labs-hub/{portainer,jellyfin,media,budgeteer-demo}`. The demo's DB dir must be **`chown 999:999`** — postgres `initdb` runs as uid 999 and fails on a root-owned directory.
- **`deploy/.env` now holds real secrets** (mode 600, gitignored). The stack has **no fallback**: `up` fails by name without them. `make gate` passes placeholders for the structural check only.
- **Reseeding needs a budgeteer checkout** — the demo DB is published on `127.0.0.1:5434` only, so tunnel in: `ssh -fNL 5434:127.0.0.1:5434 wesker@raspberrypi.local`. Runbook in `deploy/README.md`.
- Re-pristine between showings: `docker exec budgeteer-demo node apps/api/dist/db/reset.js`, then reseed. The reset preserves users/sessions (budgeteer BUD-S90).
- **The Pi's DHCP address is now `192.168.1.219`** (docs written before LH-S1 said `.185`) — which is exactly why `LABS_HUB_HOST` defaults to the mDNS name. Don't hardcode the IP.
- **Pin by digest, not tag.** `0.1.0` was published twice and now resolves to a different digest than its own contract recorded.
